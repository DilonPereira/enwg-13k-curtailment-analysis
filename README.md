# Germany §13k EnWG Renewable Curtailment Analysis

An Interrupted Time Series (ITS) empirical evaluation assessing the effect of Germany’s §13k EnWG (*"Nutzen statt Abregeln"* / "Use Instead of Curtail") trial phase on national renewable energy curtailment. 

This repository contains the complete pipeline for data acquisition, aggregation, econometric estimation, and report generation using Python and R.

---

## 📁 Repository File Structure

### 📄 Documentation & Reports
* **`enwg-13k-curtailment-analysis.pdf`**  
  The main research paper/report detailing the background, econometric methodology, model specifications, empirical findings, and policy implications.

---

### 🐍 Data Processing & Ingestion (Python)

* **`fetch_netztransparenz_data.py`**  
  Pulls raw historical redispatch and curtailment data directly from the official Transmission System Operator (TSO) API ([netztransparenz.de](https://www.netztransparenz.de/)). Handles OAuth authentication, rate-limiting, and annual data extraction into CSV format.

* **`build_weekly_curtailment_panel.py`**  
  Processes and cleans raw redispatch CSV files. Filters events for renewable curtailment (`PRIMAERENERGIEART == "Erneuerbar"`) and aggregates event-level MWh volumes into a standardized weekly panel aligned with Monday start dates. Outputs `weekly_curtailment_national.csv`.

* **`build_report_workbook.py`**  
  Consolidates clean curtailment data, generation series, key indicator callouts, and qualitative summaries into an Excel workbook (`report_data.xlsx`) configured for visualization in Excel or Tableau.

---

### 📊 Econometric Model (R)

* **`regression-analysis.R`**  
  The core econometric script. Fits Interrupted Time Series (ITS) regression models using `fixest` and `lmtest`. Evaluates pre/post trial policy levels and slope changes while controlling for:
  * Total wind and solar generation
  * Month-of-year fixed effects
  * Heteroskedasticity and autocorrelation (Newey-West HAC standard errors)
  * Confounding events (e.g., Germany's April 2023 nuclear phase-out)
  * Robustness checks (sample trimming and placebo intervention dates)
  
  Exports formatted LaTeX (`.tex`) and plain text (`.txt`) regression tables via `etable`.

---

### 💾 Data Files (CSV)

* **`redispatch_2026.csv`**  
  Raw event-level redispatch dataset extracted from *netztransparenz.de* containing detailed records of grid interventions, affected energy sources, and work volumes (MWh).

* **`Actual_generation_202101010000_202609060000_Week.csv`**  
  Weekly actual renewable power generation data obtained from [SMARD.de](https://www.smard.de/) (Bundesnetzagentur), including onshore wind, offshore wind, and photovoltaics (solar) generation in MWh.

* **`weekly_curtailment_national.csv`**  
  The aggregated weekly panel generated by `build_weekly_curtailment_panel.py`, serving as the primary input dataset for the R econometric model.

---

## 🔄 Execution Workflow

1. **Fetch Data:** Run `fetch_netztransparenz_data.py` to retrieve raw API data.
2. **Build Panel:** Run `build_weekly_curtailment_panel.py` to aggregate raw redispatch records into `weekly_curtailment_national.csv`.
3. **Run Econometric Models:** Execute `regression-analysis.R` to run the ITS regression suite and generate statistical tables.
4. **Export Report Workbook:** Run `build_report_workbook.py` to produce `report_data.xlsx` for charting and key metrics summary.
